 # 📊 Data Science Dashboard – E-Commerce Analytics

An interactive **E-Commerce Data Science Dashboard** developed using Python and Streamlit. The dashboard provides business insights through KPIs, data visualization, sales trends, customer analysis, and interactive filters.

## 🚀 Project Overview

This project analyzes a large-scale e-commerce dataset containing more than **1 million records**. The goal is to transform raw business data into meaningful insights that can support data-driven decision-making.

The dashboard allows users to explore sales performance, customer behavior, payment methods, product information, and profitability through interactive visualizations.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Streamlit
- Scikit-learn
- Jupyter Notebook
